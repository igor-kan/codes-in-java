# Kosaraju Iterative Two-Pass Directed SCC Engine (`kosaraju_scc_count_d56`)

> Category: **Graph Connectivity** | Language: **Java 21**

## Overview

Decomposes any directed graph into Strongly Connected Components using iterative reverse-postorder discovery and transposed graph DFS passes.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V + E)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- A directed cycle of length K forms exactly 1 strongly connected component.
