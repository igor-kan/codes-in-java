# Tarjan Undirected Cut-Vertices (Articulation Points) Finder (`tarjan_bridge_cut_d57`)

> Category: **Graph Connectivity** | Language: **Java 21**

## Overview

Discovers all articulation vertices whose removal disconnects an undirected connected component via DFS lowlink discovery inspection.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V + E)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- Simple cycles have zero articulation points whereas paths of length >= 3 mark interior nodes.
